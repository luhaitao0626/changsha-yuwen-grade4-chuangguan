# 长沙小学语文四年级上册 · 学习知识闯关

统编版四年级上册语文闯关小游戏：8 关 × 每关 8 题，sqlite3 持久化进度与错题本。

## 规则

- 每关 8 题，答对至少 **7/8** 过关（6/8 不过）
- 关卡顺序解锁
- 错题进入错题本，重练全对后清除；清除错题本不影响已通关进度
- 主线不含选读课文

## 本地运行

需要 Python 3。

```bash
python3 server.py
```

浏览器打开：http://127.0.0.1:43210

## 目录

- `server.py` — HTTP + sqlite3 后端
- `questions.json` / `pass-rules.json` — 题库与过关规则
- `public/` — 前端页面
